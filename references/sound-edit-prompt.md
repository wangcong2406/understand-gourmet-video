# 5.3-Flash Phase 2B：声音、剪辑与节奏账本

读取实际提供的连续视频及音轨、shot ledger 和 ASR，只输出 `sound-edit-ledgers/5.3-flash/{id}.json`。

## 必做

1. 标 shot 边界、shot duration、转场类型；至少两个 shot ID 才能写剪辑关系。
2. 区分主体运动与摄影机运动。
3. 记录对白/旁白、环境、餐具、烹饪、咀嚼、音乐、音效、静音及画内/画外来源。
4. 记录空间、时间、节奏、图形关系，以及比较、揭示、回扣、省略。
5. 记录切点与动作、语音、音乐节拍是否对齐；没有音轨证据不得从字幕推声音。
6. 先 observable，再 relation；interpretation 只写竞争解释、支持与限制。

## 禁止

- 从 `audio_timeline` 声称镜头、特写、蒙太奇或 BGM；
- 从短镜头直接推断专家注意力；
- 把后期强调署名给专家；
- 用“节奏紧张/氛围温暖”替代 shot duration、切点、音量和色温等事实。
