# 单期视频理解 Prompt（表态类·简化版）

> 用于 `content_type: "表态"` 的条目——无具体店铺，但有强观点表述
> （回应质疑、行业看法、方法论自述、年度总结）。
>
> **为什么不排除这类**：它恰恰是价值观红线的最强证据。红线的确认阈值是
> "≥1次明确表态+行为一致"——这类视频就是明确表态本身。按"非探店"
> 一刀切会丢掉四层中最容易拿到的那一层。
>
> 同样须**视频与转写同次输入**。

---

```
你的任务：理解【{专家名称}】的这一期表态类视频（编号 {编号}）。
这不是探店内容——没有具体店铺和菜品，但他在表达观点。
你会同时拿到视频原件和 ASR 语音转写稿。

═══════════════════════════════════════
【这类内容的特殊价值】
═══════════════════════════════════════

探店视频展示的是"他怎么判断"，表态视频展示的是"他为什么这么判断"。
后者是价值观层的直接证据，且是**单期即可确认**的层次
（防抖阈值：≥1次明确表态+行为一致）。

因此本 prompt 的重点与探店版不同：
- **不需要**结构化字段（无店铺无价格）
- 不强制套用探店六环节，但必须还原观点形成与表达过程：触发/质疑→展开→转折/让步→最终立场
- **重点提取**价值观红线 + 表达DNA素材

═══════════════════════════════════════
【重点提取】
═══════════════════════════════════════

1. **价值观与红线**
   - 他在捍卫什么？反对什么？
   - 情绪最强烈的时刻说了什么？（越激动越接近核心价值）
   - 有没有"绝不"式的表态？

2. **内在张力**
   - 他有没有自己纠结、自我辩护的地方？
   - 有没有承认"我也有做不到的"？
   → 张力是深度的来源，**保留不调和**

3. **表达DNA素材**（这类视频的表达密度通常高于探店）
   - 句式节奏、高频词、标志性说法
   - 情绪强度的表达方式
   - 面对质疑时的回应模式（先赞同再反驳/直接否定/追问引导/升维）
   - 停顿、重复、语速/音高/音量变化、笑/叹气、直视或移开视线
   - 即时发言、后期旁白、引用/模仿他人的区别
   - 观点如何通过开场、转折、回扣和结尾组织成一条表达弧线

4. **沉默边界**
   - 什么话题他明确说"我不懂"/"这个我不评价"？
   → 揭示他的能力认知与诚实度

5. **视频独有信号**
   - 每段标 `visual_status`、`visual_basis`、花字可读性；视觉条目标 `evidence_level`，规则同探店版
   - `audio_only` 时只写口播结构，不得想象镜头、花字、动作、BGM或剪辑
   - 微表情与完整反应序列，不把孤立表情直接翻译成态度
   - 语速、停顿、重复、音量、音高，是否直视镜头及何时移开
   - 花字、BGM、回放和剪辑位置如何强化、弱化或改写口播
   - 区分专家言行、对话者、摄影选择和后期包装的意义主体
   - 保留竞争性解释；不能唯一判断时写开放解释，不得删除

═══════════════════════════════════════
【同样的禁止事项】
═══════════════════════════════════════

❌ 把原话重述成书面语——原话逐字保留
❌ 从单期归纳"他的世界观"——只记线索
❌ 描述光线构图画质——那是给视频生成用的

═══════════════════════════════════════
【★ 事实/推测边界（与探店版同等重要）】
═══════════════════════════════════════

表态类视频里博主大量输出观点，**更容易把推测写成断言**。每条价值观记录须标：

| source_type | 含义 | 能否进 `values_triggered` |
|------|------|---|
| `blogger_explicit` | 他明确说出的立场 | ✅ |
| `blogger_hypothesis` | 他的推测（原话含"我觉得""应该是""可能"） | ✅ |
| `model_inference` | 你推断的（他没说） | ❌ **不可**，写进 B5 其他观察 |
| `externally_verified` | 有多方确认（表态类中罕见，通常用不到） | ❌ 不可 |

⚠️ 不得把你自己的解读混进他的观点。他说"这行现在挺乱的"，
   不要写成"他认为行业存在系统性造假"——那是你的引申。

⚠️ **单期表态推出的态度是候选，不是稳定价值观。**
   区分两者：
   - **红线**（如"绝不收钱推广"，明确表态+情绪强烈）→ 单期可确认，正常记
   - **从一次经历推出的倾向**（如"对米其林的务实态度"）→ 标"单次推出，待跨期验证"

═══════════════════════════════════════
【用画面纠正转写错误】
═══════════════════════════════════════

规则同探店版：画面交叉验证 > 上下文推断 > 保留存疑。
纠正记录写入 C 区，不可只留纠正后版本
（下游提取表达DNA需要未经纠正的原话）。

⚠️ 依据只填 `画面` / `上下文` / `存疑保留`，**不得编造帧编号或时间码**。
⚠️ **一处错误一行**，"纠正后"必须唯一确定，不得多处合并。
⚠️ `存疑保留` 也要给出最可能推断 + 置信度（高/中/低），不可一句"存疑"了事。

## B. 提炼层

### B1 价值观与红线
- 内容 / 触发情境 / 情绪强度（强/中/弱）
- **原话（逐字，不得重述）** / **时间戳**（`MM:SS-MM:SS`）
- `source_type`：**只能是** `blogger_explicit` / `blogger_hypothesis`
  ——**不接受 `model_inference`**（闸门查 `VALUES_MODEL_INFERENCE`）。
  红线单期即可确认、无免责声明，模型推断进来会直接成为专家画像的一部分；
  模型自己的观察请写进 B5 其他观察
- `value_type`：`红线`（明确表态，单期可确认）/ `候选倾向`（单次经历推出，待跨期验证）
- `evidence_source`：`audio` / `visual` / `both` / `inference`
- `confidence`：`high` / `medium` / `low`（这条记录本身可不可靠，区别于 source_type）

> 上述字段名与 json 的 `values_triggered[]` 一致，填写内容可直接对应过去。
> ⚠️ **原话必填且不得重述**——表态类视频的原话密度高于探店类，是表达DNA的主要来源；
> 若 json 里只有归纳没有原话，下游就只能回查 md，分层交付失去意义。

### B2 内在张力（如有）
- 他纠结什么 / 两边分别是什么 / 原话

### B3 表达DNA素材
- 句式特征、高频词、标志性说法
- 回应模式（面对质疑时）
- 完整原话示例 2-3 段

### B4 沉默边界（如有）
- 他明确不评价的话题 / 拒绝方式的原话

### B5 其他观察

### B6 视听表达过程（必填）
- 观点弧线：初始立场 → 触发/质疑 → 展开 → 转折/让步 → 最终立场
- 反应序列：刺激前基线 → 表情/身体/声音变化 → 回应 → 后续动作
- 声画关系：花字/BGM/回放/剪辑是否强化或改写口播
- 意义主体：专家 / 对话者 / 摄影选择 / 后期包装
- 开放解释：存在多义时并列解释、依据和限制

### B7 原始表达样本（必填）
按推荐、否定、反问、类比、不确定性、自我修正、分歧处理分别扫描；保存完整原话、时间戳、语境和副语言。没有某类可标未出现，不能只给概括。
```
