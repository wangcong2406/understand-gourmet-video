# 5.3-Flash 正反例

## 正例：任务相关视觉

```text
[画面][evidence_level=single_frame][visual_basis=f_00120] 年糕被掰开，内部可见红豆颗粒。
```

贡献：补充 ASR 没有的内部结构，且单帧足以支持。

```text
[画面][evidence_level=frame_sequence][visual_basis=f_0035-f_0043] 连续帧显示筷子夹起凤爪、靠近鼻部、随后入口。
```

贡献：记录判断前的信息获取动作；必须有真实连续端点。

```text
[视觉核验][visual_basis=f_0041-f_0048] 已检查但无判断相关视觉信号。
```

贡献：诚实区分“看过无信号”和“没看”。

## 反例一：对象检测注水

```text
[画面] 人物出现在画面中。
[画面] 画面中出现餐具。
[画面] 画面中出现食物（分类含 food/soup）。
```

这些只能进入 `raw_detector_observations`，不能拆成三份视觉丰富度。

## 反例二：ASR 反推画面

```text
[画面][frame_sequence] 博主凑近闻香、拨开鸡爪、入口品尝。
```

如果这些动作只是口播说了，而输入仅有不连续帧，就应写 `not_observable_from_sampled_frames`。

## 反例三：自由文章漂移

```text
# 某餐厅·深度理解
## 叙事弧光与判断轨迹
## 专家人格侧写更新
```mermaid
...
```
```

这类产物不能被 validator/merge 消费，属于失败。

## 反例四：单期偷渡稳定画像

```text
“九分烂”是他的标志性评分体系。
这证明了他的食材至上哲学。
```

正确写法：本期使用“九分烂”描述该菜口感；是否为稳定表达或判断方法待跨期验证。

## 正例：专业空间流

```text
observable: S12为俯拍近景；主菜位于画面中央，浅景深使背景餐具失焦；侧后方软光在酱汁表面形成连续高光；断面可见肥瘦两层。
relation: 该shot紧接博主“看肉皮状态”的口播，提供肥瘦与表面状态的可见依据。
interpretation: 高光可能强化油润感；限制是曝光与酱汁本身均会影响高光，不能据此判断油腻程度。
```

反例：`暖光说明餐厅很温馨，俯拍证明导演强调这道菜。`——光线/角度不能直接推出氛围或意图。

## 正例：动作与微反应

```text
action: W3:A1，00:42.12夹起→00:42.68靠近鼻部→00:43.20入口→00:44.05放下筷子。
microreaction: W3:M1，face_visibility=full_clear；基线嘴唇放松；00:43.58嘴唇收紧(onset)，00:43.76头部后撤(apex)，00:44.10恢复(offset)，强度B_slight。
interpretation A: 可能出现不适；support=随后明确说“有点腥”并停吃；limits=正在咀嚼也可能造成嘴唇收紧。
```

反例：`[画面] 他皱眉，明显不喜欢。`——客观动作与情绪解读混写，且无时间过程和后续支持。

## 正例：剪辑、节奏与声音

```text
observable: S8持续4.2秒，硬切S9特写；切点发生在“但是”之后0.2秒。AU4为画内咀嚼脆响，00:51.3–00:52.0；S9开始后环境声延续0.6秒，构成声桥。
relation: 由全景切特写补充展示断面；“但是”与切点共同标记评价转折。
interpretation: 剪辑可能强化转折；限制=不能据此认定专家本人重视该对象。
```

反例：`口播很长，所以编辑注意力高；字幕写“脆”，所以能听到脆响。`
